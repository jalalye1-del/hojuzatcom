# الحزمة الموحدة لأحدث تعديلات حجوزاتكم

بُنيت هذه الحزمة فوق الملف الأخير المرسل:
`hojuzat_current_before_merge(1).zip`.

## ما تتضمنه

- الواجهة الرئيسية لبطاقة تأجير السيارات والنقل البري والشحن الداخلي.
- مسار تأجير السيارات: الشركات، المكتب والسيارات، التفاصيل، الحجز، الدفع والفاتورة.
- مسار النقل البري: التصنيفات والشركات والرحلات والمقاعد والمسافرين والدفع والفاتورة والتذكرة.
- مسار الشحن الداخلي: الشركات والأسطول والحجز وعرض السعر والملخص والدفع والفاتورة.
- بطاقات تتبع السيارة والرحلة والشحنة.
- مسار قاعات الأفراح: الرئيسية، التفاصيل، الموعد والباقة، الإضافات، البيانات، الدفع والتأكيد.
- البنران الأصليان المرفقان للسيارات والقاعات.

## الملفات التي لم تُستبدل

لم تتضمن الحزمة `pubspec.yaml` أو ملفات الترجمة أو نماذج النقل؛ ستبقى نسخك الحالية منها كما هي.

## التركيب

1. خذ نسخة احتياطية من `C:\hojuzatcom`.
2. فك الضغط.
3. انسخ مجلدي `lib` و`assets` إلى `C:\hojuzatcom` ووافق على دمج المجلدات.
4. وافق على استبدال الملفات الموجودة التي تعرضها ويندوز.

ثم شغّل في PowerShell:

```powershell
cd "C:\hojuzatcom"
flutter pub get
flutter analyze
flutter run
```

## ملاحظة الفحص

تم فحص توازن الأقواس لجميع ملفات Dart وسلامة مراجع الملفات والأصول، واختبار ملف ZIP.
لا يتوفر Flutter داخل بيئة إعداد الحزمة، لذلك يجب تشغيل `flutter analyze` على جهازك وإرسال أي رسالة خطأ تظهر.
